# منصة إدارة أعمال المقاول (الوبران) — فرع نجران

بوابة واحدة لمدير الفرع والإدارة العليا: صفحة رئيسية تلخص موقف كل المنصات، قائمة جانبية بالتطبيقات تفتح كل منها في تبويبات أفقية، ومساعد ذكي يقرأ كل البيانات.

## البنية
- `public/` الواجهة (HTML/CSS/JS بلا خطوة بناء).
  - `js/registry.js` سجل المنصات. **إضافة منصة = عنصر واحد هنا.**
  - `js/core.js` القاعدة المشتركة ومحرك التقييم والتنبيهات وسياق المساعد.
  - `js/views.js` الصفحات والتبويبات.
  - `js/assistant.js` المساعد الذكي (Claude عبر Netlify AI Gateway، مع محرك محلي احتياطي).
  - `js/seed.js` البيانات الأولية: الرخص (ملف أكتوبر 2026، 26 رخصة) وبطاقات السلامة (67 بطاقة).
- `netlify/functions/`
  - `data.mts` → `/api/data` قراءة وحفظ في Netlify Blobs (القراءات، الرخص، البطاقات، الملخص).
  - `assistant.mts` → `/api/assistant` المساعد الذكي.
  - `daily-summary.mts` ملخص الإدارة العليا يومياً 8:10 صباحاً بتوقيت الرياض.

## الإعداد على Netlify
- `HUB_ADMIN_PIN` (اختياري): رمز يُطلب لحفظ البيانات. يُكتب في «إعدادات البوابة» على كل جهاز مخوّل.
- `HUB_AI_MODEL` (اختياري): نموذج Claude المستخدم. الافتراضي `claude-sonnet-5-5`.
- الذكاء الاصطناعي يعمل عبر Netlify AI Gateway تلقائياً بعد أول نشر إنتاجي، بدون مفاتيح.
