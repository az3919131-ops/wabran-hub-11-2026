# لوحة التوزيع اليومي — مزامنة مع منصة الوبران

لوحة التوزيع (najran-dispatch-board.netlify.app) تحفظ بياناتها داخل متصفح من يعدّها فقط.
أُضيف إليها الملف `wabran-hub-sync.js` (سطر واحد في `index.html`) ليرفع تلقائياً إلى قاعدة منصة الوبران:
- جدول الأعمال اليومية (الكهرباء) لآخر 14 يوماً من IndexedDB `wabran-edc`.
- آخر 7 جداول توزيع للعمالة والمعدات من `ndb.v1.plans` و`ndb.v1.resources`.

المزامنة عند فتح اللوحة، وكل دقيقة، وعند إغلاقها، وفقط إن تغيّرت البيانات. لا تُرفع المرفقات.
بقية ملفات اللوحة هي البناء المنشور نفسه دون تعديل.
