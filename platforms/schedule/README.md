# مزامنة منصة تقدم الأعمال (جدول الأعمال اليومي والشهري)

المنصة الأصلية `najran-wabran-dor-dashboard.netlify.app` تحفظ بياناتها (الأساس + ما يُستورد من Excel) في متصفح المستخدم فقط.
لذلك أُضيف لها:

- `wabran-nav.js` — الدخول الموحد بحساب منصة الوبران وزر الرجوع.
- `wabran-hub-sync.js` — يرفع آخر نسخة كاملة إلى `ds_schedule` في منصة الوبران عند فتح المنصة وكل دقيقة وعند إغلاقها (إن تغيّرت).
  الأرقام الشهرية تُحسب بدوال المنصة نفسها (`Calc` و`App.helpers`) فتطابق صفحة «التحليل الشهري».
- `_headers` — نفس رؤوس الموقع السابقة.

المزامنة التلقائية كل 6 ساعات في البوابة لا تستبدل نسخة المتصفح الأحدث بملف الأساس الأقدم.
