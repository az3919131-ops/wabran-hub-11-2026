# منصة إسناد أوامر العمل — دخول تلقائي من منصة الوبران

- `wabran-sso.js`: عند فتح المنصة داخل منصة الوبران تستلم رمز دخول المستخدم وتطلب من `/api/wo-session`
  جلسة بحساب «مشاهد» للقراءة فقط (`hub-viewer@wabran-najran-hub.netlify.app`)، ثم تبدأ المنصة والبيانات ظاهرة.
- `/api/wo-session` لا يعطي الجلسة إلا لمستخدم منصة الوبران الذي له وصول «إسناد أوامر العمل».
  كلمة مرور حساب المشاهد مشتقة على الخادم من `AUTH_SECRET` ولا تُخزَّن في الكود.
- قاعدة البيانات تبقى محمية: القراءة بلا دخول مرفوضة، وحساب المشاهد لا يستطيع التعديل.
- خارج منصة الوبران تعمل المنصة كما هي بدخول المحررين.
