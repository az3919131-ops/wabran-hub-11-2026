# منصة الفواتير الضريبية — تسريع العرض داخل منصة الوبران

أُضيف للمنصة الأصلية (`najran-invoice-intelligence.netlify.app`) دون تعديل كودها أو بياناتها:

- `fast-data.js`: طلبات قاعدة البيانات تمر عبر نطاق المنصة (`/sb/` ← Supabase) فلا تتأثر بحجب supabase.co،
  وقراءات العرض العام تُحفظ نسخة منها في المتصفح وتظهر فوراً إن تأخرت الشبكة أكثر من ثانية ثم تُحدَّث في الخلفية.
- `_redirects`: وكيل `/sb/*` + توجيه الصفحات للتطبيق.
- `_headers`: نفس رؤوس الموقع السابقة (السماح بالعرض داخل منصة الوبران فقط).

ومنصة الوبران تجهّز ملفات المنصة مسبقاً في المتصفح بعد الدخول.
